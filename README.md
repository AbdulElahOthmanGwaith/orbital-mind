# 🌌 Orbital Mind - نظام العقل المداري

**Orbital Mind** هو تطبيق ويب تفاعلي لإدارة الأفكار والخرائط الذهنية بأسلوب كوني فريد. يتيح لك تحويل أفكارك إلى كواكب تسبح في فضاء رقمي، حيث ترتبط الأفكار ببعضها البعض عبر روابط جاذبية تحاكي الأنظمة المدارية الحقيقية.

---

## ✨ المميزات الرئيسية | Key Features

*   **التمثيل البصري الكوني:** تحويل الأفكار إلى كواكب ملونة بأحجام مختلفة بناءً على أهميتها.
*   **روابط الجاذبية:** إنشاء روابط بين الأفكار تحاكي قوى الجاذبية، مما يجعل الخريطة الذهنية حية وديناميكية.
*   **واجهة تفاعلية:** دعم كامل للسحب والإفلات، التكبير والتصغير، والتنقل السلس في الفضاء.
*   **الحفظ التلقائي:** يتم حفظ جميع بياناتك محلياً في المتصفح (LocalStorage) لضمان عدم فقدانها.
*   **أداء عالي:** مبني باستخدام Pure JavaScript و Canvas API لضمان سلاسة الحركة حتى مع وجود مئات الأفكار.

---

## 🚀 البدء السريع | Quick Start

### التشغيل المحلي | Local Setup

يمكنك تشغيل المشروع بسهولة باستخدام أي خادم ويب بسيط:

**باستخدام Python:**
```bash
cd orbital-mind
python3 -m http.server 8000
```

**باستخدام Node.js:**
```bash
npx http-server -p 8000
```

ثم افتح المتصفح على الرابط: `http://localhost:8000`

## 🎮 طريقة الاستخدام | How to Use

1.  **إضافة فكرة:** انقر مرتين (Double Click) في أي مكان فارغ.
2.  **ربط الأفكار:** اسحب من كوكب إلى آخر لإنشاء رابط جاذبية.
3.  **تحريك الكواكب:** اسحب أي كوكب لتغيير مكانه في المدار.
4.  **حذف فكرة:** اسحب الكوكب نحو **الثقب الأسود** الموجود في أسفل الشاشة.
5.  **التنقل:** استخدم عجلة الماوس للتكبير/تصغير، واسحب الخلفية للتحرك في الفضاء.

## 🛠 التقنيات المستخدمة | Tech Stack

*   **HTML5 & CSS3:** للهيكل والتصميم البصري المتقدم.
*   **JavaScript (ES6+):** للمنطق البرمجي والمحاكاة الفيزيائية.
*   **Canvas API:** للرسم عالي الأداء.
*   **LocalStorage API:** لتخزين البيانات محلياً.
