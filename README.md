# 🌌 Orbital Mind - نظام العقل المداري

**Orbital Mind** هو تطبيق ويب تفاعلي متطور لإدارة الأفكار والخرائط الذهنية بأسلوب كوني فريد. تم إعادة تصميمه بالكامل ليقدم تجربة مستخدم عصرية وسلسة.

---

## ✨ التحديثات الجديدة | New Updates

*   **إعادة تصميم شاملة:** واجهة مستخدم عصرية تعتمد على نظام الحوسبة المكانية.
*   **معلومات التواصل:** دمج مباشر لبيانات التواصل (البريد الإلكتروني والهاتف).
*   **تحسين الأداء:** محرك فيزيائي مطور لضمان سلاسة حركة الكواكب.
*   **دعم اللمس:** تحسين التفاعل على الأجهزة اللوحية والهواتف الذكية.
